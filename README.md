DECENT EVENTS PLANNER — ADMIN PANEL

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Login with:
   Username: admin
   Password: admin123
4. Open Settings to change the password and business profile.

FEATURES
- Dashboard summary and charts
- Employees: add, edit, delete
- Bookings: add, edit, delete
- Events & Projects: add, edit, delete
- Gallery: upload, edit, delete images
- Blogs: add, edit, delete
- Payments & Salary: add, edit, delete
- Search, JSON backup/restore, profile and password settings
- Responsive layout for mobile and desktop

IMPORTANT LIMITATIONS
This is a working browser-based starter admin panel. Records are stored in the browser's localStorage on the device/browser where you use it. They do not automatically sync to other phones or computers. Clearing browser data can remove records, so export backups regularly.
The demo login is not production-grade security. Do not publish this version on the public internet or store sensitive customer/employee information until a secure backend, database, server-side authentication, and file storage are connected.
For multi-device and secure live use, deploy with a backend such as Supabase/Firebase or a custom server.
